# Keep Awake

A Quick Settings button that keeps your screen on indefinitely until you turn it off.

## Get the APK (no computer needed)
1. Create a new GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the repo's **Actions** tab. The "Build APK" run starts automatically (or tap **Run workflow**).
3. When it finishes (~3 min), open the run and download **KeepAwake-apk**. Unzip it to get `app-debug.apk`.
4. Open the APK on your phone and allow installing from that source.

## Set up
1. Open **Keep Awake** from your app drawer.
2. Tap **Allow** to give it unlimited background use. The button won't switch on until this is done.
3. Add the tile: swipe down twice → pencil icon → drag **Keep Awake** into your tiles.

## Use
- Tap the tile: screen stays on (an ongoing notification shows while active).
- Tap again, or **Turn off** in the notification, to go back to your normal screen timeout.
